1. This Project name is PytestSeleniumFramework, for learning selenium and python automation with pytest.
2. IDE required - Pycharm
3. Install python (ref. url - https://www.python.org/downloads)
4. Install pytest: pip install pytest  (at both Terminal and project level)
5. Install selenium: pip install selenium (at both Terminal and project level)
6. To generate HTML report: pip install pytest-html (at both Terminal and project level)
7. To parallel execution need to install: pip install pytest-xdist
8. Command to run parallel execution: pytest -n2 , (where 2 is the no. of worker)
9. To run script in commandline: pytest testfile_path -s -v -n=2 --html report_name.html
